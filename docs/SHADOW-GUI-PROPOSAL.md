# JV-880 shadow-mode GUI: layout proposal (DRAFT for review)

Status: built and deployed (see HANDOFF.md). This file is the original layout proposal; the mockups in `mockups/` show the current page.

## Constraints from force-shadow

- Slot `page=2` (`KNOBS+SCENE-2`). `ctrl_sock=/tmp/jv880_ctrl.sock`, `display_name=JV-880`.
- Data-driven `shadow_page.conf`, generated by `scripts/gen_shadow_page.py` (as force-dx7 does). Max 8 tabs, 64 widgets each.
- Keys in a conf are static, so there is no "current tone" selector. Per-tone editing needs one tab per tone (4 tabs), as DX7 does with OP1..OP6.
- Widgets: `knob toggle button enum_h enum_v readout stepper env bits frame`. Use `style=lcd`, `int_values=1`.
- Canvas is 1280x800 landscape. The DX7 conf uses x 36..1244 and y 88..724 under a 48px top row.

## Look: Roland JV-880 + green dot-matrix

- Palette: dark grey-black panel, LCD well in phosphor green (`#9be15d` on `#0c1a0a`), Roland-blue/grey silk-screen accents for frames and labels.
- All values sit in an LCD-style readout well in green. Knobs are dark, with a green dotted arc and a small pointer.
- Top row on every tab is a mock JV-880 display: line 1 is the patch name in large dot-matrix text with the number (`A11 Pop Brass`), line 2 is the bank/expansion name.
- Tab bar mimics the JV-880 front-panel button labels.
- Palette prototype: the existing `theme_*` keys cover it. A baked dot-matrix font for the top-row name would be a small force-shadow change (see open question 2).

## Persistent top row (all tabs)

```
[ BANK/EXPANSION readout (tap -> BANKS) ]  [ - ] A11 Pop Brass  [ + ]  [ MODE: PATCH|PERF ]
```

Uses `readout` + `stepper`, the same as DX7. `preset` runs 0..N, `preset_count` gives the total.

## Tabs (7) -- mockups in `docs/mockups/`

| # | Tab | Contents | Mockup |
|---|-----|----------|--------|
| 1 | PLAY | Output (Voice Out/Vol, Octave, Patch Level/Pan, Macro mode), the 8 macros, effect sends, Patch/Perf mode, tone on/off strip | `play.png` |
| 2 | PATCH | Control, Bend/Portamento, Reverb, Chorus (COMMON + FX merged) | `patch.png` |
| 3-6 | TONE 1..4 | Wave/FXM/pitch strip, Pitch/Filter/Amp envelope graphs with T1-4/L1-4 knobs, LFO 1 and 2 | `tone1.png`..`tone4.png` |
| 7 | BANKS | Bank/expansion list and patch list | `banks.png` |

Web-only for now: matrices (mod/aftertouch/expression), filter cutoff/reso, key-follow and velocity curves, tone delay, per-tone level/pan/sends. The tone tab is already full: filter cutoff/reso and tone level/pan are the main things I couldn't fit, and are the first candidates for a second tone view.

Mockup caveats:
- Values are fake, and the top-row `P A` / `11 P B` text is a harness artifact of the fake data.
- Font is the existing LCD font, not a dot-matrix one.
- The envelope graphs use placeholder keys. force-shadow's `env` widget wants DX7-style `<prefix>r1..4/l1..4` siblings, and JV uses `nvram_tone_<n>_penvtime1`/`penvlevel1`, so a real build needs a small force-shadow change. Envelope graph scaling would also need to become 0-127 based, with signed levels for pitch.
- `bank_index`/`patchbank_list` keys on BANKS need checking against jv_host's real get_param keys.

## Q-Link / encoder use

Physical Q-Links stay on the existing 14-knob `.xtk` CC map, so the shadow page doesn't need to duplicate that. The touchscreen is for the deeper edit.

## MidiLoop shortcut

Same as the other addons: `SHIFT+SCENE-2` opens this page (the existing page-toggle script that `KNOBS+SCENE-2` already uses), and the engine is started/stopped by the ENGINE button on the page (shown top right in the mockups). No separate engine shortcut. Done on the device as for DX7 and Maze Voice: timestamped backup of `midiloop.config`, change only the `SHIFT+SCENE-2` line, `midiloop test`, reload midiloop. Not done yet: needs the device IP, and the config line is only worth changing once the page is deployed.

## Build plan once layout is agreed

1. `scripts/gen_shadow_page.py` in this repo (adapted from force-dx7's), writes `addon/shadow_page.conf`.
2. Offline render with force-shadow's `render_harness.c` to PNG, review here before any deploy.
3. Add `shadow_page.conf` to `dist/ForceJV880`, update HANDOFF.md.
4. Staged scp + `mv` deploy, then ask before restarting `acvs`.
